# oreo-monitor

External monitor for the oreo-cloud Raspberry Pi home server.

- A GitHub Actions workflow checks the Pi every 5 minutes, including whether Docker is healthy.
- Alerts go to the owner's phone. Credentials are stored as GitHub secrets, never in this repository.
- Public repository, so the workflow minutes are free. It contains no server details or secrets.

The server's scripts and images live in the private repository `oreo-cloud`.

## Development

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install pre-commit pytest
pre-commit install
pytest
```

- Pre-commit hooks check formatting and YAML, check each commit message (one line, capitalised, at most 72 characters, no extra trailers), block commits to `main` and run the tests before a push. CI runs the same on every pull request, plus the pull request title.
- The `PR description` workflow tidies each pull request description: it removes co-author and session lines and any "generated by" or "requested by" footer. It never fails and never comments.
- Dependabot opens weekly pull requests for the GitHub Actions, which are pinned to commit SHAs.

## Changes

Every change goes through a pull request against `main` and is squash-merged by the owner. The rules are in `CLAUDE.md`.

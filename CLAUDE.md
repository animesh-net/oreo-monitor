# Repo conventions

- Never push commits to `main`, including force-pushes. Every change goes on a
  branch and lands through a pull request.
- Branches: new features use `feature/<name_feature>`, fixes use `fix/<name_fix>`.
- No AI attribution anywhere: no Co-Authored-By or session trailers in commits,
  no "Generated with…" lines or links in PR titles or descriptions.
- Never add a "Generated by Claude Code" (or similar) footer to anything:
  PR comments, reviews, review replies, issues or issue comments.
- The posting service may append that footer on its own. After creating a PR
  or posting a comment, read it back from GitHub; if a "Generated by/with
  Claude Code" line (or the `---` rule above it) was added, edit the PR
  description or comment to remove it.
- Commit author: the person whose GitHub account the session is using, never
  Claude.
